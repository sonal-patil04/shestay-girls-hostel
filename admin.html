🔥 Connect Firebase Database

Right now your data is saved in localStorage — this means it only exists in this one browser. Connect Firebase to get a real cloud database so data is saved permanently and visible from any device.

1
Go to console.firebase.google.com → Click Add Project → Name it shestay-hostel → Disable Google Analytics → Create project
2
Inside the project, click the Web icon (</>) → Register app name as shestay-web → Click Register App → You will see a firebaseConfig object — copy it
3
Open js/script.js in VS Code → Find the firebaseConfig section → Paste your copied values. Do the same in admin.html (search for firebaseConfig). Then set:
const FIREBASE_ENABLED = true;
4
In Firebase Console → click Firestore Database → Create database → Start in test mode → choose any region → Done
5
In Firebase Console → click Authentication → Get started → click Email/Password → Enable it → Save. Then go to Users tab → Add user → email: warden@shestay.in → password: Shestay@2026
6
Refresh this admin page — the status badge will change from 💾 localStorage to 🔥 Firebase Live. All new form submissions will now save to the real cloud database.
✅ After Firebase is connected: Every booking, registration, enquiry and login is stored permanently in the cloud. You can see it from any browser or device. Parents and warden can check live data.
